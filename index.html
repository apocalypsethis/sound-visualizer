麦克风用不了？按这三步排查：
  1. 换 Edge 或 Chrome 打开这个页面，不要在希沃白板软件的内嵌窗口里打开。
  2. 打开 Windows 设置 → 隐私 → 麦克风，确认「允许应用访问麦克风」和浏览器这一项都是开的。
  3. 确认白板 / 电脑接了麦克风；没有就插一个 USB 麦克风，再点一次「开启麦克风」。

📱 手机上打不开：多半是页面开在某个 App 的内置窗口里，它不会弹权限询问框 —— 把链接复制到手机自带浏览器或 Chrome 里打开再试。

〰️ 实时波形

波形越密 → 音调越高
试着从低音「啊——」慢慢滑到高音，波形会越挤越密。
波形越高 → 声音越响
小声说话波形矮矮的，大喊一声，波形会猛地长高。
波形形状 → 音色不同
口哨的波形圆滑，拍手是一下尖峰，形状就是声音的「长相」。

⛰️ 渐强渐弱练习 · 《哎呀玛利亚丢了宝石花》

唱一句歌，看你的歌声在几秒里慢慢变强、变弱

黄色虚线是目标形状，青色的是你的歌声走过的「山路」：声音越响，山路爬得越高。跟着虚线唱，让两条线长得像一点！

选好目标，点「开始唱」
先用一个长长的「啊——」来练：跟着目标形状，慢慢把声音变大、或慢慢变小。唱完点「看看我的形状」，这里会告诉你做得怎么样。
第 1 步 · 先用「啊——」长音练形状，不用唱词，只练慢慢变大、慢慢变小。
第 2 步 · 再唱《哎呀玛利亚丢了宝石花》里的一句，用刚才练好的形状唱出来。
第 3 步 · 全班一起唱，看大屏幕上全班的歌声是一座什么样的山。

📊 频谱图 · 音色的「指纹」

每根柱子是一种频率成分的强弱；圆点标出基频和它的谐波

口哨的频谱只有一两根高柱子（成分单一、纯净）；说话和拍手的柱子又多又杂（成分丰富）。对比一下，音色差别一目了然。

🧪 课堂小实验

1
吹口哨 vs 拍手

各定格一张卡：口哨是圆滑的波浪线，拍手是一根尖尖的「闪电」，频谱也完全不同。

2
唱一个长音「啊——」

保持音调不变，看波形疏密稳不稳定；再慢慢升高，数一数音调读数怎么变。

3
小声 → 大声

同一句话从耳语说到大喊，观察振幅和响度等级从「安静」跳到「大喊」。

4
模拟音色大比拼

用模拟模式在同一音调下切换四种波形，对比波形形状和频谱柱子的多少。

声音只在这台设备上实时处理，不上传、不录音、不保存。
